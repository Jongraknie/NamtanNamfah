## 🎮 รายละเอียดระบบและเกมนวัตกรรม

### 🐱 1. ดินแดนเรียนรู้ น้องน้ำฟ้า (ระดับชั้นประถมศึกษาปีที่ 2)
* **คณิตศาสตร์อนาคตใหม่ (Math Adventure):**
  * 🥕 **ตะลุยป่าแครอท:** ฝึกการบวกเลขสามหลักไม่เกิน 1000 ทั้งแบบมีตัวทดและไม่มีตัวทด
  * 🍦 **ร้านไอศกรีมพ่อมด:** เรียนรู้และทายค่าประจำหลักเลขโดด รวมถึงรูปกระจายตัวเลข
  * 🪙 **ล่าสมบัติใต้บาดาล:** ฝึกเปรียบเทียบค่าของจำนวน และเติมคำตอบในอนุกรมเลข
* **ภาษาอังกฤษปลาดาว (English Classroom):**
  * 🐡 **Book 1: Coral Reef Adventure:** ฝึกทบทวนคำศัพท์ทั่วไป สี และไวยากรณ์พื้นฐาน (`have`, `is`, `These`, `an`, `those`, `on`, `in`, `under`, `that`)
  * 🏫 **Book 2: The School Life:** ฝึกทบทวนคำศัพท์เรื่องสิ่งของและบทสนทนาโต้ตอบพื้นฐานในโรงเรียน ภายใต้ภาพปลาทะเลเคลื่อนไหวเคลื่อนที่น่ารัก
* **เขาวงกตปริศนา (EF Neon Maze Explorer):**
  * 🌀 **ด่านเขาวงกตเรืองแสง:** ฝึกทักษะการตัดสินใจและการวางแผนนำทางลูกบอลเรืองแสงผ่านแป้น D-Pad บนหน้าจอสัมผัส มีเสียงสังเคราะห์ประกอบชนกำแพง และตารางคะแนนชิงตำแหน่งสูงสุด **พระราชา/ราชินี**
* **ป่าสะกดคำภาษาไทย (Thai Spelling Challenge):**
  * ✏️ **ด่านสะกดคำป่าไม้:** รวบรวมคำสะกดผิดบ่อยและคำพ้องเสียง 20 ข้อสำหรับ ป.2 มีระบบเสียง AI อ่านนำโจทย์ ระบบเฉลยละเอียด 3 สเต็ป และสามารถพิมพ์เกียรติบัตรประกาศเกียรติคุณขนาด A4
* **ยานอวกาศทายเดือน (Space Months Dictation):**
  * 🚀 **เขียนตามคำบอกเดือนภาษาอังกฤษ:** ฟังเสียงอ่านภาษาอังกฤษต้นตำรับ (`en-US` Accent) เพื่อพิมพ์สะกดชื่อเดือนทั้ง 12 เดือน สามารถสะกดง่ายๆ ด้วยการจิ้มกล่องตัวอักษรสลับที่ด้านล่าง ซึ่งบล็อกตัวอักษรจะเปลี่ยนเป็นสีเทาเมื่อเลือกใช้ และเด้งกลับมาเมื่อกดลบ ⌫

### 🦊 2. ดินแดนเรียนรู้ น้องน้ำตาล (ระดับชั้นประถมศึกษาปีที่ 6)
* 📐 **คณิตศาสตร์ ป.6 (Math P.6):** บทเรียนและแบบฝึกฝนคณิตศาสตร์ระดับประถมศึกษาปีที่ 6
* 📝 **ภาษาอังกฤษ ป.6 (English P.6):** ทบทวนคำศัพท์และประโยคภาษาอังกฤษที่ลึกและท้าทายมากยิ่งขึ้น
* 📖 **ภาษาไทย ป.6 (Thai P.6):** ฝึกฝนการสะกดคำยาก หลักการใช้ภาษา และวรรณคดีพื้นฐาน
* 🎓 **ข้อสอบจำลองเตรียมสอบเข้า ม.1 (Exam Entrance):** ระบบทดสอบจำลองตะลุยคำถามรอบด้าน เพื่อเตรียมพร้อมน้องน้ำตาลในการสอบเข้าศึกษาต่อในระดับมัธยมศึกษาตอนต้น (ม.1)

* เข้าใช้งานผ่านหน้าสถิติ **[stats.html](stats.html)** หรือกดจากหน้าแรกเพื่อเช็คชั่วโมงการเรียนรู้ คะแนนสะสมรวม ประวัติการทำข้อสอบของน้องน้ำฟ้าและน้องน้ำตาล เพื่อวางแผนการพัฒนาความสามารถของเด็กๆ ต่อไปได้ทันท่วงที

## 🛠️ รายละเอียดการพัฒนาทางเทคนิค (Technology Stack)
* **ภาษาหลัก:** HTML5, CSS3, JavaScript (ES6+)
* **ระบบเสียง:** Web Speech API (SpeechSynthesis) สำหรับการอ่านสะกดคำและการทักทายนำทางน้องๆ
* **การจำลองคลื่นเสียง (SFX):** ใช้ Web Audio API สังเคราะห์คลื่นเสียงตอบถูก/ตอบผิดในไฟล์เดี่ยวโดยตรงโดยไม่ต้องพึ่งพาไฟล์เสียงจากภายนอก
* **การบันทึกข้อมูล:** ใช้ `localStorage` ในการบันทึกสถิติคะแนน ลีดเดอร์บอร์ด และสถิติการเล่น
* **การติดตั้งคลาวด์:** พัฒนาแบบ Single-Page & Static Application อัปโหลดขึ้นสู่ GitHub Pages ออนไลน์ได้ทันที
